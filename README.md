# Calculator

A Python/Tkinter desktop calculator.

## Quick Start

```bash
uv sync
python cal-v1.py
```

## Usage

Click number/operator buttons, press `=` to evaluate, `AC` to clear. Supports `+`, `-`, `*`, `/`, `%`, and `+/-`.

## Notes

- `main.py` is a placeholder entry point.
- `cal-v1.py` evaluates expressions with Python's `eval()`.
- Python ≥3.11 required.
