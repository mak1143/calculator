# Calculator

A calculator project with two implementations:

- **Python/Tkinter** — a desktop GUI in `cal-v1.py`
- **Web** — an HTML/CSS/JS calculator in `calculator-application/`

## Quick Start

### Python calculator

```bash
uv sync
python cal-v1.py
```

### Web calculator

Open `calculator-application/calculator.html` in a browser.

### GitHub Pages

The web calculator is deployed at https://mak1143.github.io/calculator/

## Usage

- **Python:** click number/operator buttons, press `=` to evaluate, `AC` to clear.
- **Web:** same button layout and behavior (AC, +/-, %, ÷, ×, -, +, =).

## Notes

- `main.py` is a placeholder entry point.
- `cal-v1.py` evaluates expressions with Python's `eval()`.
